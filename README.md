🧠 The "Main Diagonal" ConstraintThis project implements a specific movement cost model. While cardinal directions (N, E, S, W) have a cost of $1$, the diagonal movements (SE, NW) are calculated at $\sqrt{2} \approx 1.41$ within the Uniform Cost Search logic. This creates realistic pathfinding behavior where the AI avoids unnecessary zig-zags.
